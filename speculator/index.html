01 / 六个主题

把故事，拆成可以练习的东西。

利弗莫尔不提供机械规则，但他反复展示同几件事：市场方向、最小阻力、时机、情绪、消息和错误。我们把这些主题抽出来，和道氏、海龟放在同一张桌子上。

01 / THEME

市场只有一面

不要跟市场争论“谁对”。你的观点、仓位和自尊都不重要；价格往哪里走，才是唯一需要回应的事实。

“股市却只有一面，既不是多头的一面，也不是空头的一面，而是正确的一面。”
02 / THEME

最小阻力线

不要预测顶和底，观察价格往哪个方向最省力。当市场不断试探、失败、再试探，真正的方向会在阻力最小的路径上显形。

“推动价格沿着最小的阻力点前行。”
03 / THEME

时机与耐心

看对方向只是第一步。真正稀缺的是等到关键时点、并且在看对之后坐得住。过早入场和过早离场，都会把判断变成亏损。

“既能判断准确又能耐心坚守的人并不多见。”
04 / THEME

希望与恐惧

亏损时希望它回来，盈利时害怕它消失——这是投机者最常见的两种本能。系统交易要求你在别人贪婪时恐惧，在别人恐惧时保持希望。

“投机者最主要的敌人总是由投机者自身而生。”
05 / THEME

贴士与内部人

消息传到散户耳朵里时，往往已经被定价。依赖别人告诉你“该买什么”，等于把退出按钮交到别人手里。

“没有什么人能依靠别人告诉他该怎么去做才能有大的盈利。”
06 / THEME

错误与生存

破产不是终点，重复同一种错误才是。亏损是学费，但只有被记录、被复盘、被写回规则的亏损，才真正变成经验。

“我一生都在犯错误，但是，在我亏损的经历中，我积累了经验，获得了另一种财富。”
